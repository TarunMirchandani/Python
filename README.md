# Python Programming Notes: Harvard CS50P

A comprehensive summary and reference guide based on Harvard University's **CS50’s Introduction to Programming with Python** full university course. This guide covers everything from core syntax to advanced programming paradigms to help you jump straight into coding.

## 📚 Course Overview
CS50P is designed for learners with or without prior programming experience. It teaches how to read, write, test, and debug Python code by covering essential concepts:
* Functions and variables
* Conditionals and loops
* Exceptions and libraries
* Unit tests and file I/O
* Regular expressions
* Object-oriented programming (OOP)

## 🛠️ Development Environment
To write Python, you need a plain-text editor (avoid word processors like Microsoft Word as they add hidden formatting). 

**Visual Studio Code (VSCode)** is highly recommended for its powerful features:
* **Syntax Coloring:** Visually distinguishes code elements (e.g., functions like `print` appear in distinct colors).
* **Integrated Terminal:** Allows you to run your code without leaving the editor.
* **Debugging Tools:** Helps catch and fix errors efficiently.

## ▶️ Running Python Programs
The Python interpreter reads a source file and translates it into machine-readable binary code.

1. Create a file ending in the `.py` extension (e.g., `main.py`).
2. Open your terminal and execute the file using the Python interpreter:
   ```bash
   python main.py
   ```
## 🧩 Core Concepts & Roadmap
As you progress through the course, you will build on the foundations by exploring these critical topics:

* **Conditionals:** Execute specific blocks of code based on true/false boolean tests.
* **Loops:** Repeat actions a set number of times or while a specific condition holds true.
* **Exceptions:** Handle runtime errors gracefully using `try` and `except` blocks to prevent crashes.
* **Libraries:** Import and reuse third-party code modules to avoid reinventing the wheel.
* **Unit Tests:** Write automated tests that verify your individual code functions work exactly as intended.
* **File I/O:** Read from and write data to files for persistent storage between program runs.
* **Regular Expressions:** Define precise search patterns to validate, clean, or extract text data.
